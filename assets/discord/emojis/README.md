# Emotes de MapasBot

Esta carpeta contiene la familia completa de emotes de MapasBot, generada con la paleta turquesa, azul cartográfico, dorado pergamino y coral. Todos están preparados como PNG RGBA de 128×128 para Discord.

Los 16 IDs actuales ya están configurados como valores predeterminados en `emojis.js`. Las variables de entorno son opcionales y permiten reemplazar un ID sin tocar el código:

```env
EMOJI_MAPAS_MAP_ID=ID_DEL_EMOJI
EMOJI_MAPAS_JOIN_ID=ID_DEL_EMOJI
EMOJI_MAPAS_DROP_ID=ID_DEL_EMOJI
EMOJI_MAPAS_RETURN_ID=ID_DEL_EMOJI
EMOJI_MAPAS_REVIEW_ID=ID_DEL_EMOJI
EMOJI_MAPAS_ACTIVE_ID=ID_DEL_EMOJI
EMOJI_MAPAS_EMPTY_ID=ID_DEL_EMOJI
EMOJI_MAPAS_FULL_ID=ID_DEL_EMOJI
EMOJI_MAPAS_ALERT_ID=ID_DEL_EMOJI
EMOJI_MAPAS_VERIFIED_ID=ID_DEL_EMOJI
EMOJI_MAPAS_LYMHURST_ID=ID_DEL_EMOJI
EMOJI_MAPAS_BRIDGEWATCH_ID=ID_DEL_EMOJI
EMOJI_MAPAS_FORT_STERLING_ID=ID_DEL_EMOJI
EMOJI_MAPAS_THETFORD_ID=ID_DEL_EMOJI
EMOJI_MAPAS_MARTLOCK_ID=ID_DEL_EMOJI
EMOJI_MAPAS_ZONA_ROJA_ID=ID_DEL_EMOJI
```

Mientras un ID no esté configurado, el bot usa automáticamente un emoji Unicode de respaldo.
